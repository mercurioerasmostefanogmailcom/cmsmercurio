# MercurioCMS 1.0.0-RC2

Questa candidata aggiorna l'editor delle pagine integrando Summernote Lite 0.9.1.

## Modifiche
- Editor visuale in italiano con formattazione, stili di paragrafo, caratteri, dimensioni, colori, elenchi, tabelle, collegamenti e modalità schermo intero.
- Modalità separata per codice HTML indentato e anteprima.
- Inserimento immagini e documenti tramite la libreria media di MercurioCMS.
- Dipendenze JavaScript incluse localmente: jQuery 3.6.0 e Summernote Lite 0.9.1.
- Bozze temporanee e sanificazione HTML lato server mantenute.
- Licenze MIT delle dipendenze incluse in `licenses/`.

## Nota di verifica
Sono stati eseguiti controlli statici di sintassi e integrità del pacchetto. Prima del rilascio definitivo è necessario completare il collaudo funzionale nel browser e verificare salvataggio, modifica e pubblicazione di pagine reali.
